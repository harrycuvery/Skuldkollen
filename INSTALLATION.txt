SKULDKOLLEN – UPPDATERING OCH INSTALLATION PÅ IPHONE

Den här versionen innehåller knappen + Lägg till person och Ta bort. Befintliga namn och betalningar sparas när du ersätter filerna på samma GitHub Pages-adress och i samma webbläsare/enhet.

UPPDATERA GITHUB:
1. Packa upp ZIP-filen i appen Filer på iPhone.
2. Öppna GitHub-repositoryt Skuldkollen och gå till huvudmappen (main / root).
3. Ta bort den gamla ZIP-filen om du vill – den används inte av Pages.
4. Välj Add file > Upload files och ladda upp filerna från den uppackade mappen direkt i repositoryts rot. Om GitHub frågar om att ersätta filer, välj att ersätta.
5. Commit changes.
6. Vänta tills GitHub Pages publicerat ändringarna. Stäng sedan Skuldkollen helt och öppna webbplatsen igen i Safari. Om hemskärmsappen visar gammal version, öppna webbplatsen i Safari först och ladda om.

VIKTIGT OM DATA:
Betalningshistorik sparas lokalt i webbläsarens lagring. Radera inte webbplatsdata och använd samma webbadress/enhet. Ta gärna en säkerhetskopia via Inställningar > Spara kopia innan uppdatering.

INSTALLERA SOM APP:
Öppna HTTPS-adressen i Safari > Dela > Lägg till på hemskärmen.
